Catalog Description

Basic components of web development which include aspects of design as well as current development technologies. Development technologies include, but are not limited to, HTML/XHTML, JavaScript, and CSS. Other technologies discussed may include Java Applets, CGI programming, ASP.NET and PHP.

Actual Description

Basic components of client-side web development which include aspects of design as well as current development technologies. Development technologies may include, but are not limited to, HTML, CSS, JavaScript, TypeScript and frameworks such as jQuery/Vue/React. Foundational components of the modern web including protocols, APIs and web services.

Prerequisites: CST 211 or CST 313 or instructors consent.

Objectives

Upon completion of this course, students will be able to:
  1. Design and implement web sites using HTML 5 and CSS3
  2. Work with JavaScript frameworks such as jQuery and React
  3. Build and deploy websites using tools such as Vite and webpack
  4. Integrate web services for a dynamic user experience
  5. Create modern and maintainable web sites.
  6. Build a functional website based on a designer-provided sketch

Grading

The final grade will be determined from the following breakdown: Assignments, Quizzes, and Labs 60%; Mid-Term 20%; Final 20%

The grade calculations will be as follows:

90% + -> A; 80% + -> B; 70% + -> C; 60% + -> D; Less than 60% -> F

Assignments

The due date of all assignments will be announced when they are assigned. Late assignments may be given a 20% penalty for each day past due.

Labs

Labs are each worth 10 points and must be checked off via Teams during a lab period, or by special arrangement with the instructor. There is no partial credit for labs. If anything is missing/incorrect, you will be asked to correct it and have it signed off before receiving credit.

Tests/Quizzes

There will mid-term and a final exams to demonstrate that you have learned how to use web technologies, and also understand the reasoning behind certain structure/design decisions. Smaller quizzes will also be assigned along the way and will allow for a single retake. No retakes are available for exams.

Use of Artificial Intelligence Tools

In the current landscape, everyone will be expected to use AI tools when entering the workforce. AI can magnify our ability to create, but for it to do so, we must develop that ability first. It is perfectly acceptable to use AI to help you explore the materials of this course and better understand them, but it is not okay to simply copy questions into chat and paste the answers back into assignments. You should have the expectation that at any time I may ask you to explain your understanding of anything that you turn in.

Cheating

Academic dishonesty is defined as cheating, plagiarism or otherwise obtaining grades under false pretenses. Plagiarism is defined as submitting the language, ideas, thoughts or work of another as one's own; or assisting in the act of plagiarism by allowing one's work to be used in this fashion. Cheating is defined as, but not limited to: obtaining or providing unauthorized information during an examination through verbal, visual or unauthorized use of books, notes, text and other materials; obtaining or providing unauthorized information concerning all or part of an examination prior to that examination; taking an examination for another student or arranging for another person to take an exam in one's place; altering test answers after submittal for grading; changing grades after grades have been awarded; or altering other official academic records.
